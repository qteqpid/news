## 研究论文与评测

- **[Agentic Coding in the Wild](https://arxiv.org/abs/2608.00101)**
  论文分析 GitHub Copilot 在生产规模下的 agentic coding traces，帮助理解真实开发场景中 AI 编码代理的行为模式。（来源：arXiv）
- **[RAG-TESTER：自动化端到端测试 RAG 系统](https://arxiv.org/abs/2608.00054)**
  论文提出 RAG-TESTER，用于自动化测试检索增强大模型系统，关注从检索到生成的端到端质量。（来源：arXiv）
- **[SIRIN：检测 RAG 和记忆增强 LLM 的上下文幻觉](https://arxiv.org/abs/2608.00033)**
  SIRIN 提供一套语义不一致识别工具，用于发现 RAG 和 memory-grounded LLM 系统中的上下文幻觉。（来源：arXiv）
- **[JudgeArena：可复现的 LLM-as-a-judge 评测框架](https://arxiv.org/abs/2608.02620)**
  JudgeArena 试图统一 LLM judge 的评测流程，解决不同 judge 设置下排名不稳定和难复现的问题。（来源：arXiv）
- **[MemArena：端侧个人记忆助手基准](https://arxiv.org/abs/2608.02613)**
  MemArena 面向端侧个人记忆助手，评测模型处理私密、长期和多场景个人信息的能力。（来源：arXiv）
- **[Evaluating OpenAI's Privacy Filter](https://arxiv.org/abs/2608.02616)**
  论文独立评估 OpenAI 隐私过滤器在 42 个跨语言、跨领域 PII 检测基准上的表现。（来源：arXiv）
- **[Preferred, Not Safer](https://arxiv.org/abs/2608.02617)**
  论文指出临床场景中的 pairwise preference 不一定能代表安全性，提醒医疗 AI 评测不能只看偏好分数。（来源：arXiv）
- **[Can LLM Agents Price Competitively?](https://arxiv.org/abs/2608.00102)**
  论文提出 agentic commerce 场景下的动态多属性拍卖基准，用来评估 LLM agent 是否能在商业定价中有效竞争。（来源：arXiv）
